# Everly waitlist

A single-page waitlist for Everly, a wedding planning platform starting in Philadelphia.

## Preview

```bash
npm install
npm run dev
```

## Formspree

The form is connected with `@formspree/react` to `https://formspree.io/f/mvkkoeqp`.

The form id lives in `src/formspree.js`. Replace `mvkkoeqp` if you create a new Formspree form. The confirmation appears only after Formspree accepts the submission.
